# 子母畫面播放器 (Picture-in-Picture) Chrome 擴充套件

點一下工具列圖示（或按快捷鍵 **Alt+P**），就能把目前頁面正在播放的影片，
用瀏覽器原生的子母畫面浮窗播放。再點一次即可關閉。

## 功能特色
- 自動挑選頁面上「正在播放且畫面最大」的影片
- **浮窗內建自訂控制列**（採用 Document Picture-in-Picture）：
  - ▶ / ⏸ 播放、暫停
  - «10 / 10» 後退、前進 10 秒
  - 可拖曳的播放進度條（含目前時間 / 總長度；直播影片自動停用）
  - 播放速度切換（0.5x ~ 2x）
  - 控制列平常隱藏，**游標移到浮窗上才淡入**，靜止 2.5 秒後自動隱藏
- 舊瀏覽器 / 不支援的框架會自動退回原生子母畫面（透過 Media Session 仍支援播放暫停與快轉倒退）
- 自動把 Netflix、YouTube、friDay 影音等網站疊在影片上的 HTML 字幕鏡射到浮窗（瀏覽器原生 `<track>` 字幕本來就會跟著影片一起進浮窗）
- 支援 iframe 內嵌影片：跨網域 iframe 會注入子框架處理；**同網域 iframe 裡的播放器（friDay 影音等）會把整個播放器框架搬進浮窗**，網站自己的字幕與控制列照常運作（搬移時播放器會重新載入一次，擴充套件會自動接續播放位置）
- 再次點擊 / 再按快捷鍵 = 關閉子母畫面（toggle）
- 不需要任何後端、不收集任何資料

## 安裝方式（開發者模式載入）
1. 開啟 Chrome，網址列輸入 `chrome://extensions`
2. 右上角開啟「**開發人員模式 / Developer mode**」
3. 點「**載入未封裝項目 / Load unpacked**」
4. 選擇這個 `pip-extension` 資料夾
5. 完成！工具列會出現圖示，到任何有影片的頁面點一下即可

## 使用方式
- 在有影片的分頁，點擊工具列上的擴充套件圖示
- 或直接按快捷鍵 **Alt+P**
- 要關閉子母畫面，再點一次圖示或再按一次快捷鍵

## 注意事項
- `chrome://`、Chrome 線上應用程式商店等特殊頁面無法使用（瀏覽器限制）
- 少數網站會用 `disablePictureInPicture` 禁止 PiP，這類影片無法浮窗
- friDay 影音這類把播放器放在同網域 iframe 的網站，浮窗裡顯示的是網站自己的播放器（沒有本套件的控制列），開啟與關閉浮窗時播放器各會重新載入一次
- 需要 Chrome / Edge 等支援 Picture-in-Picture API 的瀏覽器

## 自訂快捷鍵
到 `chrome://extensions/shortcuts` 可以修改或移除預設的 Alt+P。

## 權限說明
| 權限 | 用途 |
| --- | --- |
| `activeTab` + `scripting` | 只在你「點擊圖示 / 按快捷鍵」的當下，把切換 PiP 的腳本注入目前分頁 |
| `host_permissions: <all_urls>` | 為了支援 **iframe 內嵌影片**（例如文章頁裡嵌的播放器），需要把腳本注入跨網域的子框架，`activeTab` 無法涵蓋這種情況 |

腳本只在你主動觸發時執行，平常不會讀取任何頁面內容；本擴充套件**沒有後端、不發送任何網路請求、不收集任何資料**。
